## 腕部辅助计次实测

这部分测量尚未完成。先做轻重量对照测试，并由测试者或在场观察者人工计数作为基准；不要边负重边操作手机。若使用视频作对照，应取得参与者同意并妥善保管，App 本身不上传视频。

优先覆盖卧推、宽距高位下拉、窄距高位下拉、宽距坐姿划船、窄距坐姿划船、肩推、侧平举和深蹲。记录自由重量／器械、佩戴侧、动作幅度、节奏与负重；包括正常训练节奏、慢速离心、短暂停顿和准备动作等条件。宽窄变式即使共用轨迹，也应分别实测。

建议先每个动作至少观察 3 组探索问题，再为拟宣称支持的范围设计包含多个用户与多组训练的独立验收样本；3 组探索测试不能证明准确率。

可报告的测量包括：

- 每组绝对误差：`abs(显示次数 - 人工次数)`。
- 总次数相对偏差：`sum(abs(显示次数 - 人工次数)) / sum(人工次数)`，保留每组明细，避免平均值掩盖失败动作。
- 无需修正的组比例：`完全正确的组数 / 实测组数`。
- 准备动作误触发、休息误触发、固定手腕漏计及异常计数的具体场景。

这些指标不是医疗精度验证，也没有预先承诺的通过阈值。发布负责人应先定义接受范围、样本覆盖与失败处理，再依据数据决定保留哪些辅助轨迹、哪些默认手动。未覆盖条件写为未验证，不能把单人一次实验外推到所有用户。
