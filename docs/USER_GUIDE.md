# 组迹使用手册

本手册对应首版源码。使用 iOS 17+ 的 iPhone 和 watchOS 10+ 的 Apple Watch；也可以只在 Watch 上建立计划并训练。

## 第一次训练

1. 在 iPhone「计划」中选择预置计划，或创建自己的计划。手表也支持创建、编辑计划。
2. 为每个动作填写名称、目标组数、每组目标次数、重量和休息时间。先用较轻、熟悉的重量检查计次表现。
3. 如果需要辅助计次，选择与动作相符的轨迹。卧推、宽窄高位下拉、宽窄坐姿划船、肩部动作均有相应模板或轨迹。宽距和窄距名称会分别保留，但计次算法不会识别握距。
4. 在配对设备都可用时等待同步。iPhone「设置」可查看同步状态并点「立即同步」。以手表实际显示的计划为准后再开练。
5. 在 Watch 打开计划，选择「使用健康数据开始」或「仅记录组数与次数」。前者请求健康权限；后者只记录动作、组数和次数。
6. 安全就位后点击「开始第 X 组」。辅助计次只在这一组处于进行状态时采样。
7. 放下器械、检查显示次数，用 `−` / `+` 校正，再点「完成第 X 组」。**只有确认完成的组会进入历史。**
8. 休息倒计时结束后，由你开始下一组。完成目标组数不会自动切换动作；由你点击「下个动作」。
9. 结束训练前核对已确认组数，确认结束。本地记录会保存，并在连接可用时同步至 iPhone；已启用健康记录且系统允许时，另保存本次 HealthKit 训练。

## 避免忘记组数

界面显示当前动作、当前组序号和次数。每次点击完成一组才增加已完成组数；调整次数不会增加组数。目标次数是计划参考，不代表达标后会自动替你确认一组。

训练进度按各动作「已完成组数与目标组数中的较小值」求和，再除以计划总组数，上限 100%。一个动作的额外组不会替代跳过的另一个动作。因此完成度不意味着重量或每组次数都达标；查看组记录才能了解实际次数与重量。

切换动作或结束训练时，当前尚未确认的次数不会自动保存。若需要保留，应先完成本组。误按结束前请阅读确认内容。

## 辅助计次怎样使用

辅助计次根据手腕加速度的周期变化估算次数，需要你的手腕随动作有稳定运动。它不是器械传感器或动作识别系统，不会自动识别你正在做哪一种动作，也不能判断动作标准程度。

- 手表佩戴稳固，使用与计划匹配的动作轨迹。首版没有个人灵敏度校准界面。
- 第一组仔细对照真实次数。换器械、握距、动作速度、佩戴侧或动作幅度后，应重新观察。
- 拿放哑铃、调整护腕、喝水和准备动作可能被误判；只有准备好才开始本组。
- 深蹲、静态支撑、很慢的离心、半程动作和手腕几乎固定的器械训练，可能漏计或多计。深蹲默认手动，可在编辑动作时主动改为辅助计次。
- 用 `−` / `+` 修正结果；误差明显时改用手动模式，不要为了让算法计数而改变安全动作。

首版只有合成信号的程序测试，没有真实训练准确率数据。页面出现的自动／辅助功能，不代表每次都能精确记录。

## 自动编排与动作编辑

iPhone「计划」中的「自动编排」可根据训练目标、可用器械和每周天数生成计划预览，确认后添加。它使用固定规则模板，不会读取身体指标，也不会自动调整负荷、训练周期或恢复安排。

在计划编辑页可添加动作，修改动作名称、组数、目标次数、重量和休息时间，并重新排列顺序。名称与计次轨迹分开设置：把名称改成「窄距划船」后仍应选择坐姿划船轨迹。正在进行的训练使用开始时的计划快照；在另一设备改计划不会改写已经确认的组。

## 健康数据与权限

健康模式记录力量训练，读取获准的本次训练心率和活动能量，并请求写入训练与活动能量的权限。自动计次来自 CoreMotion，与心率并非同一数据源；关闭健康权限并不等于一定关闭腕部动作估计。

不授权、设备无法提供数据或系统暂时未返回时，仍可以记录组数和次数。没有测量值时不应把空值理解为 0；心率或能量缺失不表示没有训练。

可以在系统健康隐私设置中修改授权。App 不替你删除健康 App 里的记录；如果删除组迹本地记录，也需在健康 App 中单独管理原先保存的训练。

## 暂停、中断和恢复

暂停、休息和结束会停止辅助计次采样；恢复后按界面继续。App 意外退出后，保存的训练草稿以暂停状态恢复，传感器不会自行重新启动。

未运行有效健康训练会话时，App 进入后台会主动暂停本组，避免系统挂起后界面仍声称正在计次。仅本地记录模式请保持 App 在前台；抬腕后检查状态再继续。健康模式的后台持续采样仍须按真机验收表测试。

进程退出会中断原 HealthKit 会话。恢复草稿以本地记录为主，不把中断前的健康会话补写成一条完整连续训练。请在健康 App 检查是否存在系统保留的训练片段；需要健康记录时，重新开始一场训练并在结束时确认保存。

## 同步、导出与删除

计划和训练记录保存在设备本地；配对设备通过 Apple 的 WatchConnectivity 交换数据。同步不是实时网络服务：设备断开、系统延迟投递或 App 尚未安装都可能造成等待。先保留原设备上的记录，连接恢复后再检查。

iPhone「设置」可导出 JSON 并通过系统分享面板保存到你选择的位置。导出文件可能包含动作名称、训练时间、重量、次数、心率和活动能量，应按个人健康记录保管。首版提供导出，**没有 JSON 导入／一键恢复功能**。

删除计划会同步至配对设备，但保留已有训练历史；删除训练记录会同步至配对设备。iPhone 的「清除所有组迹数据」会清除本机计划、历史和草稿，并在同步后清除配对设备中清除时间之前的计划与历史，**不是仅清除当前手机**。离线另一端可能稍后才收到清除操作。

Watch 也提供「使用与数据」→「清除所有组迹数据」。确认「清除全部并放弃当前训练」时，会同时放弃当前尚未保存的训练，并丢弃尚未结束的健康会话；不会删除 Apple 健康中已经保存的历史。只有手表在身边时，也能通过此入口清除无法读取的数据并重新开始。

清除还会移除 App 自己管理的旧损坏数据归档、待发旧同步内容和临时导出副本；HealthKit 中已保存的数据和你已经分享到其他位置的 JSON 文件不随清除自动删除。清除前阅读确认提示，先保存需要保留的导出文件，并确认两端最终状态。

数据损坏导致不能正常读取时，iPhone 导出可能保留原始损坏文件内容，用于人工排查；这种恢复用文件不保证可直接解析，也不代表 App 已提供自动导入修复。
